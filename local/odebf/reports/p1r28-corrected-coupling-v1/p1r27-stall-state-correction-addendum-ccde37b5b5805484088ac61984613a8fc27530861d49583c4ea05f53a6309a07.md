# P1R27 stall 상태 정정 부록

상태: `APPEND_ONLY_CORRECTION`; 원본 P1R27 보고서는 변경하지 않았다.

## 정정 대상

원본 보고서의 “Stall 상태에서는 … z/W를 함께 hold했다”는 문장은 raw accepted-transition receipt와 일치하지 않는다. 올바른 사실은 다음과 같다.

> P1R27 현재 구현의 `WRITER_CLF_SEMANTIC_STALL`에서는 W write는 0이었지만 controller z target은 계속 이동했다.

## FACT

- 원본 보고서 SHA-256: `f1b05789437ebf30e8c93ac07ea2c1bd6b51c56868f90f1ade96cc178f30fa09`.
- 분석 범위는 P1R27 B10 production 8개 arm의 accepted transition 64개이다.
- 이 중 stall은 54개다.
- 54/54 stall에서 `materialization.realized_bf16_step_energy`의 다섯 layer 합은 정확히 0이었다.
- 54/54 stall에서 `target_write_realization.realized_norm`은 모든 request에서 0이었다.
- 동시에 54/54 stall에서 `target_write_realization.intended_norm`의 최대값은 양수였다. transition별 최대 intended norm 범위는 `9.129113239023792e-05`–`0.03920700496283293`이다.
- 따라서 현재 구현은 stall에서 W를 유지했지만, 선택된 target displacement는 0이 아니어서 z target은 계속 전진했다.

## INFERENCE

이 정정은 P1R27의 기존 판정 `TECHNICAL_PASS / CURRENT_IMPLEMENTATION_SCIENTIFIC_FAIL`을 바꾸지 않는다. 다만 stall totality가 W와 z를 함께 고정했다는 설명은 폐기한다. P1R28은 final stall에서 W와 z 해시가 모두 동일해야 통과하도록 별도 fail-close receipt를 둔다.
