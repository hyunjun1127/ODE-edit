- 감사일: 2026-07-30
- 대상: `job 15517`, `mv0_llama_c3_v3`, `mv0_qwen_c3_v3`

## 확인 범위와 해석 경계

지정된 두 run의 `manifest.json`, `events.jsonl`, `summary.json`, Slurm
stdout/stderr와 `sacct/scontrol`, v3 preflight, 두 독립 분석 보고서,
그리고 `compare_tensors`/equivalence predicate만 읽었다. raw prompt,
target, generation 및 underlying model/moments/projector 파일은 읽지 않았다.

이 감사는 Motivation 신호, sequential retention, ODE-Edit의 유효성 또는
baseline 대비 기대 개선폭을 지지하지 않는다. 그 판단은 MV-1 이후
held-out diagnostic의 몫이다.

## cosine > 1 telemetry 판정

Exact-byte tensor인데도 일반 cosine은 Llama `1.01296–1.01401`, Qwen
`1.00554–1.01729`다. `compare_tensors`가 tensor를 FP32로 만든 뒤
`vector_norm`과 `sum(ref*cand)`를 서로 독립적인 FP32 reduction으로
계산하고 `_ratio`가 결과를 clamp하지 않는다. 큰 tensor에서 두 reduction의
누적/반올림 경로가 달라져 동일 tensor조차 계산상 Cauchy bound를 넘은
telemetry 오류로 판단한다. 실제 tensor 불일치 증거가 아니다.

Equivalence predicate는 이 materialized/general cosine을 gate로 쓰지
않는다. Exact bytes, 동일 layer hash, relative/max error 0,
teacher/NLL error 0, trace pass와 factor `c_cosine=1.0`이 모두 통과했다.
따라서 **MV-0 PASS를 뒤집지 않으며 MV-1 진입 자체도 막지 않는다.**

다만 이 scalar는 정량 근거로 사용 금지다. MV-1에서 cosine/directional
metric을 해석하기 전 FP64 accumulation과 범위 invariant regression을
적용해야 한다. 즉 **fix-next-but-not-block**이며, 수정 전 cosine 기반
MV-1 claim만 차단한다.

## CI materialization과 최종 red 판정

Persisted schema에는 aggregate paired equivalence CI endpoint가 별도
필드로 materialize되지 않았다. 그러나 양 모델의 모든 sampled paired
primary difference가 exact zero이고 byte/hash equality가 더 강한
deterministic 증거이므로 이번 implementation closure의 blocker로 보지
않는다. 후속 schema에는 paired scalar와 CI endpoint를 명시적으로 남겨
통계 gate의 재현성을 높여야 한다.

결론적으로 동시 실행, exact child 자원, 양 모델 `3/3/3`, artifact
firewall, provenance, no-write trace와 exact rollback이 모두 통과했다.
**두 고정 모델에 대한 MV-0 implementation fidelity는 closure `PASS`다.**
MV-1은 진행 가능하되, cosine 정량 사용 전 telemetry fix가 필요하다.

## GH 후속 조치

Red 판정 뒤 `compare_tensors`의 cosine만 chunked FP64 accumulation과
`[-1,1]` range invariant로 교체했다. 큰 exact tensor 회귀 test를 추가했고
전체 CPU suite `46/46`이 통과했다. Update application, fidelity
predicate, model/EasyEdit code에는 손대지 않았다. 이 수정이 tracked
commit으로 고정되기 전에는 MV-1을 제출하지 않는다.
