## 1. Proposal에서 온 내용

- same-snapshot rewrite-side allocation signal은 큰 ODE 실험 전에 작은
  held-out diagnostic에서 actual local progress로 이어지는지 먼저
  확인한다.
- §10.8은 C1 fold `0`의 12 case, 두 모델, `q=1/256`, exact six-arm order,
  primary `progress(score_mix)-progress(frozen_static_mix)`와 model별 balanced
  gate를 사전 고정한다.
- §10.9는 C1 pair 판정별 다음 wave를 배타적으로 고정한다. Pair clear이면
  locked `untouched` 20-case pair 한 번만 허용하고 fold1은 금지한다.
  Gray 또는 architecture-conditional일 때만 fold1 한 번을 허용한다.
- 이 범주는 설계와 판정 규칙의 출처일 뿐 관측 효과의 증거가 아니다.

### pair execution technical gate

Slurm은 요청에서 고정 제공된 technical facts만 사용했고 재조회하지 않았다.

- Job `15576` parent와 두 child는 모두 `COMPLETED`, exit `0:0`이다.
  두 child는 같은 `02:28:04`에 시작했다.
- 각 child는 GPU 1, CPU 8, `65000M`; parent는 GPU 2, CPU 16,
  `130000M`이다.
- 두 모델 모두 planned/attempted/pass/failure `12/12/12/0`, outcome
  `72`, rollback exact이며 error와 OOM은 `0`이다.
- 두 summary에서도 Llama step `15576.0`, Qwen step `15576.1`의
  `COMPLETED 0:0`, artifact valid, empty error codes, complete six-arm
  panel, valid firewall/receipt와 exact rollback이 일치한다.
- Matched-`C` distance spread는 두 모델 모두 `0`; energy 최대 spread는
  Llama `3.930214223594455e-13`, Qwen
  `9.576245081199114e-11`이며 각각 analyzer contract를 통과했다.
- No-op absolute progress 최대값은 두 모델 모두 `0`이고, §10.8의 floor를
  적용한 effective replay envelope `e_m`은 각각 `1e-12`다.

따라서 pair execution technical hard blocker는 없다.

| Llama | `1e-12` | `0.008755276600519816` | `0.006667003035545349` | `0.00555419921875` | `12/12` | clear |

- Llama와 Qwen 모두 `mean(D)>e_m`이다.
- 두 모델 모두 trimmed mean과 median이 `e_m`보다 크고 positive sign도
  `>=7/12`이므로, 필수 robust 조건 셋 중 하나가 아니라 셋 모두를
  만족한다.
- Paired bootstrap mean 95% CI도 Llama
  `[0.00441025123000145, 0.013934093713760377]`, Qwen
  `[0.017130000640948613, 0.12305578043063482]`로 기록된다. 다만 CI
  endpoint는 hard gate로 사용하지 않았다.
- 양 모델의 core 방향이 일치하고 mean/trimmed/median conflict가 없으며
  sign이 `6/12`가 아니다. 따라서 pair clear이며
  architecture-conditional과 gray는 아니다.
- 양 모델의 mean과 trimmed mean이 envelope 이하가 아니므로 routing kill
  conjunction은 성립하지 않는다. Adaptive primary가 null도 아니므로
  finite-panel oracle을 근거로 한 controller/static-policy pivot도
  성립하지 않는다. 참고 oracle mean은 Llama
  `0.008755276600519816`, Qwen `0.0627475877602895`다.

  confirmatory fold, case 추가, threshold 변경, policy/controller retuning
  또는 refit도 허용하지 않는다.
