## 2. 네 범주

### Proposal에서 온 내용

Raw proposal을 다시 열지 않고 implementation spec에 canonical하게 정리된
범위만 사용했다.

- fixed direct-z와 same-snapshot layer proposal 아래 event별 routing
  opportunity가 존재하는지 검사한다.
- outcome-blind analytic utility가 actual progress를 예측해 static allocation
  대비 회수 가능한 효과를 만드는지가 Motivation의 핵심이다.
- static allocation으로 충분하거나 analytic utility가 actual progress를
  예측하지 못하면 현재 routing/controller 방향을 kill 또는 pivot한다.

### Repo/protocol에서 확인한 사실

- 고정 action set은
  `{layer_4, layer_5, layer_6, layer_7, layer_8, uniform}`이다.
- fraction은 `{1/256, 1/64, 1/16}`, probe ratio는 `1/4`다.
- 동일 calibration case `18447`, `3176`, `15669`를 두 model에 사용했다.
- covariance는 model별 기존 moment 다섯 개를 verified read-only로
  load했고, projector는 hash/size만 검증하며 deserialize하지 않는
  계약이다.
- 이 pilot은 3-case descriptive execution/calibration pilot이며 paper claim,
  expected gain, C0 budget lock을 승인하지 않는다.

### GH 추정

- 양 model에서 `uniform`이 oracle까지 포화한 것은 단순 controller 실패보다
  더 강한 조기 경고다. 현재 six-arm set 안에서는 event별로 reroute할
  opportunity 자체가 관측되지 않았다.
- `uniform − ordered_global_alpha`의 양수 차이는 event-specific routing보다
  synchronous/static geometry 차이일 가능성이 크다. 이를 ODE-Edit method
  gain으로 부르면 baseline/geometry confound가 된다.
- Qwen은 sign concordance가 안정적이어도 magnitude calibration tail이
  불안정하다. C0에서도 통과 fraction이 없으면 현재 analytic controller를
  유지한 confirmatory 실행은 resource waste다.

### 사용자 확인 필요

- 없음. 사용자는 감사를 필수 최소 범위로 제한하고 Llama/Qwen을 동시에
  빠르게 실행하라고 이미 지시했다. 이 audit은 추가 실험 범위를 확장하지

## 6. Firewall, rollback, recompute

- Structured JSON에서 raw `prompt`, `subject`, `answer/target`, token IDs,
  logits, raw generation, weights/checkpoint key를 찾지 못했다.
- request ID는 모두 full lowercase SHA-256이고 양 model에서 동일하다.
- raw context template는 persist하지 않았고 model별 context manifest ID만
  남았다.
- direct-z는 model별 3개라는 count/hash/size metadata만 확인했으며 tensor를
  열지 않았다.
- 총 138개 outcome 모두 `status=completed`,
  `rollback_exact=true`; summary도 양쪽
  `all_rollbacks_exact=true`다.
- 108개 operational arm과 18개 ordered contextual arm의 C-energy가
  event별 `fraction × native_c_energy`와 허용 오차 내 일치했다.
- model별 기존 covariance 5개만 `covariance_files_loaded`에 있고
  `projector_files_loaded=[]`다. Manifest는
  `verified-read-only; recompute-and-download-blocked` 및
  `never-deserialized` 정책을 기록한다.
- Pair log에는 download, moment/projector recompute, OOM, non-finite,
  rollback error가 없다.

따라서 지정된 artifact/log 범위에서는 firewall·rollback·recompute
위반이 관측되지 않아 **PASS**다. 외부 EasyEdit filesystem의 immutable
notarization까지 수행한 감사가 아니므로 “정책과 실행 artifact가
일치했다”를 넘는 주장은 하지 않는다.

## 7. Model별 calibration과 routing 조기 신호

Locked derivative gate는 complete `18/18`, sign concordance `>=0.80`,
median relative error `<=0.25`, p90 `<=0.75`를 모두 요구한다.

| model | fraction | sign ITD | median error | p90 error | pilot gate |
| --- | --- | ---: | ---: | ---: | --- |
| Llama | `1/256` | 1.0 | 0.0398 | 0.0847 | PASS |
| Llama | `1/64` | 1.0 | 0.0783 | 0.1726 | PASS |
| Llama | `1/16` | 1.0 | 0.1803 | 0.3506 | PASS |
| Qwen | `1/256` | 1.0 | 0.0931 | 1.1391 | **FAIL** |
| Qwen | `1/64` | 1.0 | 0.1962 | 1.2712 | **FAIL** |
| Qwen | `1/16` | 1.0 | 0.3753 | 1.1600 | **FAIL** |

Llama의 largest-passing pilot candidate는 `1/16`이지만 C0 lock은 아니다.
Qwen은 passing fraction이 없다. Qwen 실패는 주로 case `15669`의 magnitude
tail이며 sign은 모두 일치한다. 이는 “방향은 맞지만 finite-step 효과
크기를 현재 derivative로 calibrate하지 못함”과 일치한다.

더 중요한 routing 결과는 양 model이 같다.

- controller action: 모든 `case × fraction`에서 `uniform` (`18/18`)
- calibration-retrospective best static: 모든 fraction에서 `uniform`
- event-wise retrospective oracle: 모든 case/fraction에서 `uniform`
- controller − static: 모든 관측값 `0`
- oracle − static: 모든 관측값 `0`

따라서 현재 candidate set에서 관측된 event-specific routing ceiling은
양 model 모두 0이다. 이것은 **routing Motivation에 불리한 조기
신호**다.

`controller − ordered_global_alpha`는 양 model의 모든 case/fraction에서
양수였지만 ordered arm은 oracle candidate가 아닌 contextual arm이다.
이 contrast는 synchronous `uniform` geometry의 static advantage, ordered
path 차이, event routing을 분리하지 못한다. 이를 expected ODE-Edit gain으로
보고하거나 두 contrast를 더하는 것은 금지한다.

Selected arm의 exact satisfaction은 Llama `0/9`, Qwen `2/9`였고 native
full reference는 각각 `2/3`, `3/3`이었다. 작은 fraction의 smooth utility
diagnostic이라는 설계상 technical failure는 아니지만, 관측 progress를 edit
success 개선률로 번역할 수 없다는 추가 경고다.

## 8. Cross-model scientific kill risks

1. **No routing opportunity**
   - 동일 세 case에서 양 model 모두 static `uniform`이 event-wise oracle까지
     포화했다.
   - C0에서도 near-tie-adjusted oracle upper bound가 replay envelope와
     분리되지 않으면 current six-arm routing은 kill한다.

2. **Analytic calibration asymmetry**
   - Llama는 세 fraction을 모두 통과했지만 Qwen은 하나도 통과하지 못했다.
   - C0에서도 Qwen passing fraction이 없으면
     `analytic_utility_calibration_failure`로 기록하고, pooled Llama
     결과로 rescue하지 않는다. 현재 controller를 고정한 confirmatory
     실행은 block/pivot한다.

3. **Static geometry confound**
   - `uniform`이 ordered contextual arm보다 강한 관측은 event routing 없이도
     설명된다.
   - 향후 gain attribution은 best static `uniform`을 baseline으로 유지해야
     하며 ordered arm만 대비해 method gain을 만들면 안 된다.

4. **Cross-model pooling invalidity**
   - case ID는 같지만 context manifest ID는 Llama
     `3020b3f5...`와 Qwen `e0c5f61d...`로 다르고 raw utility scale도
     다르다.
   - model별 estimand를 먼저 판정하고, paired case-ID resampling의
     equal-weight sensitivity 외 raw progress pooling은 금지한다.

5. **Outcome/coverage gap**
   - 세 case 모두 single-token target이고 selected-arm exact success가
     낮다.
   - multi-token failure를 사후 제외하거나 smooth utility를 exact edit
     success/retention으로 바꾸어 부르면 kill한다.

6. **Resource waste**
   - Qwen GPU reserved peak가 92.83%다.
   - C0 lock 전 backward controller, 추가 model state, MV-2 refresh를 함께
     열지 않는다. C0 kill criterion이 발동하면 confirmatory GPU를 제출하지
     않는다.

## 9. Full C0 next gate

### CONTINUE

- 동일 사전 고정 split, action set, utility, denominator, receipt contract로
  model별 C0 20-case calibration을 완료한다.
- Llama/Qwen은 기존처럼 하나의 paired allocation에서 동시에 실행한다.
- model별 fraction gate, best static, controller policy를 C0에서만 잠근다.
- C0에서도 failure/missing을 ITD에 남기고 finite-only 분모로 바꾸지 않는다.

### KILL / PIVOT

- 두 model 모두 near-tie-adjusted oracle upper bound가 replay envelope와
  분리되지 않으면 current routing direction을 kill한다.
- Qwen에서 어떤 fraction도 derivative criterion을 통과하지 못하면 current
  analytic magnitude controller는 calibration failure로 block/pivot한다.
- oracle은 있으나 outcome-blind controller가 static을 회수하지 못하면
  controller를 kill/pivot하며 ODE refresh로 우회해 rescue하지 않는다.

### 계속 BLOCK

- 3-case pilot 기반 C0 fraction lock
- expected ODE-Edit improvement 수치
- positive routing claim
- confirmatory C1–C3 또는 untouched U 실행 승인
- MV-2 refresh, displacement/retention, long-horizon claim

이 audit이 허용하는 가장 강한 결론은 다음이다.

> 두 model의 동시 C0 pilot은 기술적으로 정상 완료됐지만, 양 model에서
> static `uniform`이 retrospective oracle까지 포화해 event-specific routing
> opportunity가 관측되지 않았고 Qwen은 모든 fraction의 derivative magnitude
> gate에 실패했다. 3-case pilot이므로 연구를 지금 확정 kill하지는 않되,
> full C0 calibration만 계속하고 결과가 반복되면 confirmatory 전에 현재
> routing/controller를 kill 또는 pivot해야 한다.
