# Native/scaled training-axis observations

The initial Middle native job measured the required canonical pair endpoints
but not their six-context training NLL. A report must not substitute canonical
rewrite NLL for that quantity. The next admitted A native process therefore
observes the seven saved Middle W0/We/N/scaled states under the same frozen We
essence teacher. Subsequent native processes record the quantities directly.

The existing DirectObjective is reused with a zero-dimensional coefficient
interface and the exact saved physical weight as its base. There is no
gradient, optimizer, target recomputation, support projection, or change to the
saved endpoint. The native-action contribution is computed relative to We
using the same frozen M+I and native denominator. All resulting values are
observation-only; PS/NS and these added observations do not select alpha.

This is additional evaluation within the authorized A deliverable, not a new
writer/candidate. It is charged to the admitted job and recorded separately
as `native_train_quantity_observation` and observation-only forward counts.
Original Middle source/results remain immutable. The first cost estimate did
not include this later-discovered observation gap; final actual cost prevails.
