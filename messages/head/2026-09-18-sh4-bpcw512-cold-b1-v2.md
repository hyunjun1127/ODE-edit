## 3. 구현과 과학 계약

원 지시문 전체를 실행 사양으로 삼되 이번 batch 범위를 B1로 제한한다.

- Llama-3-8B-Instruct pinned revision, FP32/eager/TF32 off, L4 down_proj 하나, W0/zeroM4, 원 native L2=1 등 수치설정 불변. 동일 O0 first100(고유100)의 **fresh same-host native 한 번**을 N4/BPCW512가 공유한다.
- R512 = S64+Reserve320+사전 결정한 추가 train128. Dev128/Report256을 train에 넣지 않는다. 입력/중복/tie 선정 규칙을 결과 전에 봉인한다. W0 deterministic raw-argmax max16 answer capsule과 독립 Dev128 capsule을 새로 준비한다. 기존 S64 full-distribution teacher를 이 capsule로 오인하지 않는다.
- 동일 W0-generated prefix의 **모든 보호 위치와 full vocabulary**에서 choice를 검사한다. Top8은 provenance이며 competitor 제한이 아니다. EOS/censor/shift/padding/RoPE/token tie를 명시한다. W0 답변을 사실 정답으로 주장하지 않는다.
- current canonical/native old/new 전체 valid-token K_E와 native allowed space의 교집합 Q에서 D=DQ, D K_E=0. Native immutable WN에서 FP32 materialize한다. full raw gradient의 actual-center RHS와 양의 dual reconstruction 부호를 유지한다.
- 전체512 reference, round1 최대512/round2 최대1024 exposed rows, 이전 pair 유지·gradient 현재 center 재계산, 최대1536 pair-scalar gradient/2 local QP/2 candidate scan/1 final full guard. 임의 ridge·norm cap·gradient 평균·추가 z·추가 arm/sweep 금지.
- GSS는 전체 local QP working-set 순서이며 bank/gradient 축소가 아니다. 같은 문제의 full-QP/most-violation CPU audit을 남긴다. per-reference dense W-gradient512개 저장 대신 factor화한다. full-vocab competitor forward와 two-logit-row backward 비용을 구분한다.
- native 전체 choice 안전 시 D=0 `NATIVE_ALREADY_FEASIBLE` 허용. reserve만 채우려고 보정하지 않는다. first reference-safe candidate에 current guard 한 번, 실패하면 native fallback. Reference 위반 fallback은 reference PASS가 아니다.
- official P/N·Dev는 online solver/selection에 넣지 않는다. Report256 미개봉. B1 Past64는 N/A(0), 후속 구현이 있더라도 B2 실행은 금지.
- accepted/fallback 모두 자기 committed state의 native history exactly once; 후보/observer append0. W/M/registry/RNG/context/reference/ledger atomic checkpoint와 duplicate commit 방지.
- NaN/Inf/OOM/gradient/hash/projector 등 기술 실패와 finite budget/fallback을 구분한다. 수치 ceiling/FD/KKT/quality gate를 임의로 완화하지 않는다. 기술 오류는 source-backed RCA와 실패/비용을 먼저 보존·보고하고 승인된 B1 내 최소 수리만 새 immutable attempt로 검증한다. 정책/과학조건 변경은 하지 않는다. 유효한 불리한 결과를 수리 대상으로 삼지 않는다.
