# ODE-Alloc Proposal Report

## Barrier-Guided Multi-Step Layer Allocation for One-Shot Knowledge Editing

- **Project:** ODE Edit
- **Proposal type:** 현재 multi-step parameter editing과 병렬로 검증할 독립 메커니즘
- **핵심 원칙:** **다중 step은 edit 자체가 아니라 layer allocation coefficient를 찾는 데만 사용하며, 실제 model parameter update는 마지막에 한 번만 수행한다.**

---

## 1. 제안 요약

기존 locate-then-edit 방식은 하나의 direct target과 native delta를 여러 candidate layer에 고정 비율로 분배한다. 본 제안은 delta의 방향과 총 edit 구조는 유지하되, 각 layer에 적용할 상대 weight를 historical knowledge와 original pretrained knowledge를 보존하는 방향으로 adaptive하게 찾는다.

전체 과정은 다음과 같다.

```text
현재 모델에서 native target/delta를 1회 계산
        ↓
모델을 실제로 수정하지 않은 채 coefficient q만 T-step 탐색
        ↓
historical / pretrained barrier를 만족하는 최적 allocation 선택
        ↓
선택된 weighted delta를 모든 candidate layer에 한 번만 atomic commit
```

따라서 현재 연구 중인 multi-step ODE-edit와 상태 공간이 다르다.

| 구분 | 현재 multi-step ODE-edit | ODE-Alloc |
|---|---|---|
| Multi-step state | model parameter 또는 hidden-state trajectory | layer coefficient trajectory |
| 중간 model mutation | 있음 | 없음 |
| target/delta 재계산 | 가능 | 없음; 처음 계산한 값을 고정 |
| 최종 edit | 여러 중간 update의 누적 | 최종 allocation을 한 번 commit |
| 주된 질문 | 어떤 edit path가 안전한가 | 같은 native edit을 layer에 어떻게 배분할 것인가 |

---

## 2. 연구 가설

### H1. Adaptive allocation 가설

동일한 native delta라도 layer별 적용 비율을 edit마다 조정하면, native의 고정 분배보다 새 edit efficacy를 유지하면서 historical forgetting과 pretrained drift를 줄일 수 있다.

### H2. Dual-barrier 가설

Historical edits와 original pretrained knowledge는 서로 다른 보존 대상이므로 하나의 평균 penalty로 합치는 것보다 별도 barrier로 제약하는 방식이 더 안정적이다.

### H3. Coefficient-space ODE 가설

일반적인 Adam/PGD coefficient tuning과 동일한 evaluation budget을 사용할 때, barrier-aware velocity projection이 constraint violation과 unsafe endpoint 선택을 줄인다.

### H4. One-shot sufficiency 가설

현재 multi-step parameter editing의 이점 중 상당 부분이 parameter trajectory 자체보다 adaptive layer allocation에서 온다면, ODE-Alloc은 더 적은 model mutation과 낮은 구현 복잡도로 유사한 보존 성능을 낼 수 있다.

## 3. 방법

### 3.1 Native delta basis 고정

Sequential edit step을 \(t\), 현재 모델을 \(\theta_{t-1}\), 최초 pretrained model을 \(\theta_0\), candidate layer 집합을 \(\mathcal L\)이라 한다.

새 edit에 대해 native editor가 계산한 layer별 update를

\[
\Delta^{\mathrm{nat}}_{t,l}, \qquad l\in\mathcal L
\]

이라 한다. Inner loop 전체에서 다음을 고정한다.

- direct target \(z^*\)
- key와 covariance
- layer별 native delta
- candidate layer 집합
- current/pretrained teacher output

즉, coefficient 탐색 중에는 target이나 delta를 다시 계산하지 않고 실제 model parameter도 변경하지 않는다.

초기 V1에서는 native delta construction을 그대로 사용한다. 이는 residual construction 개선과 allocation 개선을 분리하기 위함이다. Direct per-layer delta basis는 후속 V2에서만 검증한다.

### 3.2 Native-equivalent allocation

Native layer share를 \(\alpha^{\mathrm{nat}}\in\Delta^{m-1}\)라 하고, unconstrained coefficient state \(q\in\mathbb R^m\)를 native-centered softmax로 변환한다.

\[
\alpha_l(q)
=
\frac{\alpha_l^{\mathrm{nat}}\exp(q_l)}
{\sum_j \alpha_j^{\mathrm{nat}}\exp(q_j)},
\qquad q_0=0
\]

Virtual edited model은 다음과 같다.

\[
\theta_t(q)
=
\theta_{t-1}
+
\sum_{l\in\mathcal L}
\frac{\alpha_l(q)}{\alpha_l^{\mathrm{nat}}}
\Delta^{\mathrm{nat}}_{t,l}
\]

따라서

\[
q=0 \Rightarrow \alpha(q)=\alpha^{\mathrm{nat}}
\Rightarrow \theta_t(q)=\theta_t^{\mathrm{nat}}
\]

가 정확히 성립한다. 이 native-equivalence가 구현의 첫 번째 필수 sanity check다. Native share가 0인 layer는 basis에서 제외하거나 작은 양의 prior로 재정의한다.

### 3.3 Edit feasibility barrier

Canonical prompt와 paraphrase prompt를 포함한 새 edit loss를

\[
L_E(q)
=
L_{\mathrm{canonical}}(q)
+
\lambda_{\mathrm{para}}L_{\mathrm{paraphrase}}(q)
\]

로 둔다. Main constraint는 adaptive allocation이 native보다 edit efficacy를 악화시키지 않도록 설정한다.

\[
h_E(q)
=
L_E(0)+\epsilon_E-L_E(q)
\]

\(h_E(q)\ge 0\)이면 native-equivalent edit 성능 이내의 feasible point다. Native 자체가 benchmark threshold를 만족하지 못하는 사례는 별도 native-failure subset으로 보고하고, 이때만 edit-loss descent를 우선 velocity로 사용한다.

### 3.4 Historical knowledge barrier

Historical buffer \(\mathcal H_t\)는 이전 edit의 target, canonical prompt, paraphrase를 포함한다. 평균 loss만 사용하면 일부 과거 edit의 catastrophic failure가 가려질 수 있으므로 CVaR 또는 smooth maximum을 사용한다.

\[
D_H(q)
=
\operatorname{CVaR}_{\rho}
\left(
\left[
\ell_i(\theta_t(q))-\ell_i(\theta_{t-1})
\right]_+
\right)
+
\beta_H
\mathbb E_{x\in\mathcal H_t}
\operatorname{KL}
\left(
 p_{\theta_{t-1}}\,\|\,p_{\theta_t(q)}
\right)
\]

Historical target loss가 주항이며 current-model KL은 보조항이다. 동일 subject-relation에 새 값이 들어오는 경우, obsolete target은 hard preservation set에서 제거해 상충 constraint를 피한다.

### 3.5 Original pretrained knowledge barrier

Pretrained anchor set \(\mathcal B_0\)는 edit entity/relation과 겹치지 않는 general/locality prompt와 \(\theta_0\)의 teacher output으로 구성한다.

누적 edit를 되돌리려 하지 않고 이번 edit가 추가한 drift만 측정한다.

\[
D_P(q)
=
\mathbb E_{x\in\mathcal B_0}
\left[
\operatorname{KL}
\left(p_{\theta_0}\,\|\,p_{\theta_t(q)}\right)
-
\operatorname{KL}
\left(p_{\theta_0}\,\|\,p_{\theta_{t-1}}\right)
\right]_+
\]

Inner loop에서는 cached top-\(k\) logits KL 또는 hidden-state proxy를 사용할 수 있으나, held-out 평가는 full functional metric으로 수행한다.

### 3.6 Native-relative dual budgets

절대 threshold보다 안정적인 초기 설계를 위해 native endpoint를 기준으로 budget을 둔다.

\[
B_H=D_H(0)+\epsilon_H,
\qquad
B_P=D_P(0)+\epsilon_P
\]

\[
h_H(q)=B_H-D_H(q),
\qquad
h_P(q)=B_P-D_P(q)
\]

이 설계에서는 초기점 \(q=0\)이 기본적으로 feasible하며, ODE-Alloc은 native보다 더 안전한 endpoint를 찾는 문제로 정의된다.

### 3.7 Preservation objective와 coefficient-space ODE

두 damage 중 큰 항이 scalar weight 때문에 무시되지 않도록 normalized smooth maximum을 사용한다.

\[
J_{\mathrm{pres}}(q)
=
\tau\log\left[
\exp\left(
\frac{D_H(q)}{(D_H(0)+\delta)\tau}
\right)
+
\exp\left(
\frac{D_P(q)}{(D_P(0)+\delta)\tau}
\right)
\right]
+
\lambda_q\lVert q\rVert_2^2
\]

Base velocity는 다음과 같다.

\[
u(q)=
\begin{cases}
-\nabla_q L_E(q), & h_E(q)<0 \\
-\nabla_q J_{\mathrm{pres}}(q), & h_E(q)\ge 0
\end{cases}
\]

각 step에서 작은 coefficient-space CBF-QP를 푼다.

\[
(v^*,\xi^*)
=
\arg\min_{v,\xi\ge0}
\frac12\lVert v-u\rVert_2^2
+
\frac{\rho}{2}\lVert\xi\rVert_2^2
\]

subject to

\[
\nabla h_k(q)^\top v
+
\kappa_k h_k(q)
\ge
-\xi_k,
\qquad k\in\{E,H,P\}
\]

그 후 Euler step을 적용한다.

\[
q_{s+1}=q_s+\eta_s v_s^*
\]

Continuous-time barrier 조건이 finite step에서 자동 보장되지는 않으므로, 각 step 뒤 exact loss를 다시 확인하고 위반 시 backtracking 또는 step rejection을 수행한다.

### 3.8 Joint update와 BF/DF 정리

Main method는 모든 layer coefficient를 동시에 갱신하는 **joint vector optimization**이다. 이는 BF에 가까운 구조지만, 실제로는 layer를 순서대로 방문하지 않는 orderless update다.

Shallow-to-deep, deep-to-shallow, random coordinate update는 모두 ablation으로만 둔다. DF식 greedy 결정은 layer interaction과 방문 순서 confound를 다시 만들기 때문에 main mechanism으로 사용하지 않는다.

### 3.9 Best feasible endpoint와 one-shot commit

마지막 step을 무조건 채택하지 않고, trajectory 중 다음 조건을 만족하는 point에서 \(J_{\mathrm{pres}}\)가 가장 작은 endpoint를 선택한다.

\[
h_E(q)\ge0,\qquad h_H(q)\ge0,\qquad h_P(q)\ge0
\]

선택된 \(q^*\)로부터 \(\alpha^*=\alpha(q^*)\)를 계산하고, 실제 parameter update는 마지막에 한 번만 수행한다.

\[
\theta_t
\leftarrow
\theta_{t-1}
+
\sum_{l\in\mathcal L}
\frac{\alpha_l^*}{\alpha_l^{\mathrm{nat}}}
\Delta^{\mathrm{nat}}_{t,l}
\]

## 4. 알고리즘

```text
Input:
  current model θ_{t-1}, pretrained model θ_0, new edit e_t,
  candidate layers L, historical buffer H_t, pretrained anchor B_0

1. 현재 모델에서 z*, keys, covariance, native layer deltas를 한 번 계산한다.
2. current/pretrained teacher outputs와 q=0의 native losses를 cache한다.
3. q ← 0, best ← native endpoint로 초기화한다.
4. for s = 1 ... T:
     a. native-centered softmax로 α(q)를 계산한다.
     b. model parameter를 바꾸지 않고 virtual weighted delta를 주입한다.
     c. L_E, D_H, D_P와 세 barrier를 계산한다.
     d. edit infeasible이면 edit descent, 아니면 preservation descent를 base velocity로 둔다.
     e. coefficient-space CBF-QP로 velocity를 projection한다.
     f. Euler step을 시도하고 exact barrier 평가로 backtracking/rejection한다.
     g. feasible하며 J_pres가 개선되면 best를 갱신한다.
     h. min_steps 이후 수렴 조건을 만족하면 종료한다.
5. best allocation을 모든 candidate layer에 한 번만 atomic commit한다.
6. history buffer와 mechanism log를 갱신한다.
```

권장 초기 설정은 다음과 같다.

- `min_steps = 3`
- `max_steps = 8` 또는 `10`
- step sweep: \(T\in\{1,3,5,8,10\}\)
- candidate layers: 현재 native 후보 중 우선 4–6개
- historical batch: recent 50% + reservoir 50%
- pretrained batch: fixed stratified anchor pool
- 두 step 연속 objective 개선과 allocation 변화가 모두 임계값보다 작고, 모든 barrier가 feasible일 때 종료

## 5. 구현 계획과 계산량 제어

### 5.1 Virtual low-rank injection

Native update가 \(\Delta_l=U_lV_l^\top\)인 경우 매 step마다 전체 weight를 materialize하지 않고 linear output에 다음 항만 더한다.

\[
r_l(q)\,U_l(V_l^\top x),
\qquad
r_l(q)=\frac{\alpha_l(q)}{\alpha_l^{\mathrm{nat}}}
\]

Gradient는 \(q\)에 대해서만 유지한다. Optimizer/QP state는 \(O(|\mathcal L|)\)이며, 실제 병목은 barrier batch의 activation graph다.

### 5.2 필수 최적화

- direct target, keys, covariance, native deltas를 edit당 한 번만 계산
- current/pretrained teacher logits cache
- top-\(k\) KL 또는 selected-token KL 사용
- history/pretrained anchor를 하나의 microbatch로 결합
- fixed-size historical reservoir
- candidate layer 수 제한
- 마지막 endpoint만 materialize 및 commit
- 주기적으로 held-out full evaluation을 수행하되 inner loop에는 사용하지 않음

## 6. 빠른 검증을 위한 실험 설계

### 6.1 Main table

| 방법 | Delta basis | Coefficient search | 실제 commit | 목적 |
|---|---|---|---|---|
| Native | Native | 없음 | 1회 | 기준선 |
| Generic Adaptive Penalty | 동일 native basis | Adam/PGD, matched NFE | 1회 | 일반 coefficient tuning baseline |
| **ODE-Alloc** | 동일 native basis | Dual-barrier CBF-QP | 1회 | 제안 방식 |
| Best Single Layer | 동일 basis 중 하나 | exhaustive 또는 dev 선택 | 1회 | weight collapse/selection 진단 |
| Current ODE-edit | 현재 설계 | parameter-space multi-step | 여러 회 | 병렬 연구 축과 직접 비교 |

Generic optimizer와 ODE-Alloc은 다음을 반드시 동일하게 맞춘다.

- candidate layers
- native delta basis
- optimization batch
- forward/backward evaluation 횟수
- early-stop budget
- final one-shot commit 방식

### 6.2 평가 지표

| 축 | 핵심 지표 |
|---|---|
| New edit | efficacy, target margin, paraphrase/generalization |
| Historical retention | 이전 edit 성공률, worst-decile, CVaR damage |
| Pretrained preservation | locality/general accuracy, \(\theta_0\)-relative incremental KL |
| Sequential stability | edit index별 retention curve와 AUC, final retention |
| Constraint quality | barrier violation rate, slack 사용량, native fallback 비율 |
| Mechanism | allocation entropy, effective layer 수, layer별 weight 분포 |
| Efficiency | wall-clock/edit, NFE, peak memory, commit 횟수 |

Optimization buffer와 held-out evaluation set은 분리한다. Hyperparameter 및 threshold는 dev set에서 정하고 held-out 결과로 재조정하지 않는다.

### 6.3 실행 우선순위

#### P0. 구현 sanity check

1. \(q=0\)이 native parameter delta를 numerical tolerance 내에서 정확히 재현한다.
2. Inner loop 동안 실제 model parameter가 변하지 않는다.
3. `T=0` 결과가 native와 동일하다.
4. Joint update 결과가 candidate layer 배열 순서에 불변이다.
5. Final commit이 정확히 한 번 수행된다.
6. Best endpoint가 없으면 native로 안전하게 fallback한다.

#### P1. 작은 sequential pilot

우선 다음 세 방법만 짧은 edit stream에 실행한다.

- Native
- Generic Adaptive Penalty
- ODE-Alloc

Pilot 목적은 성능 우열보다 다음을 확인하는 것이다.

- native 외 feasible endpoint가 실제로 존재하는가
- coefficient가 의미 있게 이동하는가
- historical/pretrained barrier가 서로 다른 allocation을 요구하는가
- CBF-QP가 generic optimizer보다 violation을 줄이는가
- 8–10 step 내 수렴하는가

#### P2. Main sequential table

Pilot이 통과하면 Best Single Layer와 Current ODE-edit를 추가하고, 동일 benchmark와 동일 edit order에서 비교한다. 빠른 smoke run은 1 seed로 하되 최종 결과는 여러 seed와 edit order로 확인한다.

#### P3. 핵심 ablation

우선순위가 높은 ablation만 수행한다.

1. dual barrier / historical only / pretrained only
2. joint / shallow-to-deep / deep-to-shallow
3. \(T\in\{1,3,5,8,10\}\)
4. CVaR / mean historical loss
5. native basis / direct per-layer basis V2
6. fixed total strength / optional global scale \(s\) V2

## 7. 판정 기준

### 7.1 Adaptive allocation 채택 조건

다음이 만족되면 adaptive layer allocation 가설을 지지한다.

- 새 edit efficacy가 사전 정의한 native tolerance 안에 있음
- historical 또는 pretrained preservation이 held-out에서 개선됨
- 다른 preservation 축에서 유의한 악화가 없음
- 개선이 특정 edit order나 단일 seed에만 의존하지 않음

### 7.2 ODE/CBF 메커니즘 채택 조건

ODE-Alloc은 matched-NFE generic optimizer보다 다음 중 하나 이상을 안정적으로 보여야 한다.

- 더 낮은 barrier violation
- 더 낮은 native fallback 또는 slack 사용량
- 더 좋은 efficacy–preservation Pareto frontier
- 더 작은 step 수에서 유사한 endpoint 품질

Generic optimizer와 차이가 없다면 **adaptive allocation은 유지하되 ODE 자체를 핵심 기여로 주장하지 않는다.**

### 7.3 현재 ODE-edit와의 관계

ODE-Alloc이 current ODE-edit와 유사하거나 더 좋은 preservation을 보이면서 commit 횟수, wall-clock 또는 memory를 줄이면 one-shot 대안으로 우선한다.

반대로 current ODE-edit만 일관되게 우수하다면, 그 이점은 단순 allocation이 아니라 target/delta 재계산 또는 parameter trajectory에서 오는 것으로 해석할 수 있다.

## 8. 주요 실패 모드와 대응

| 실패 모드 | 해석 | 대응 |
|---|---|---|
| \(q\)가 거의 0에서 움직이지 않음 | native allocation이 충분하거나 barrier gradient가 약함 | gradient scale, anchor quality 확인; 결과 자체도 negative evidence로 보고 |
| 한 layer에 weight가 붕괴 | 실제 edit별 layer selection 또는 basis scale 불균형 | Best Single Layer와 비교; 필요 시에만 cap/entropy floor 추가 |
| V1이 개선되지 않음 | native residual/delta 방향 자체가 부정확할 수 있음 | direct per-layer basis V2로 allocation 가설을 분리 검증 |
| Historical과 pretrained barrier 충돌 | constraint infeasibility | slack과 fallback 비율 보고; conflict sample 제거 원칙 명시 |
| Inner buffer에서는 개선, held-out에서는 악화 | barrier overfitting | buffer/held-out 완전 분리, anchor 다양화, periodic full eval |
| Continuous barrier는 만족하지만 Euler step 후 위반 | discretization error | exact post-step 평가와 backtracking/step rejection |
| 계산량이 예상보다 큼 | activation backward가 병목 | cached logits, top-k KL, microbatch, layer 수와 step 수 축소 |

## 9. 기대되는 기여

본 제안의 핵심 기여는 단순히 layer weight를 학습하는 것이 아니라 다음 결합에 있다.

1. **Native-equivalent initialization:** \(q=0\)에서 기존 editor를 정확히 재현한다.
2. **Mechanism isolation:** target/delta construction을 고정해 allocation 효과만 분리한다.
3. **Dual functional barriers:** historical edits와 original pretrained knowledge를 별도로 보호한다.
4. **Coefficient-space multi-step ODE:** 모델이 아니라 작은 allocation state만 반복 갱신한다.
5. **Best-feasible one-shot commit:** 탐색 중 model mutation 없이 최종 endpoint를 한 번만 적용한다.
6. **Matched-NFE mechanism test:** generic coefficient optimizer와 공정하게 비교해 ODE의 실질적 필요성을 검증한다.

## 10. 최종 제안

초기 main experiment는 다음 구성으로 고정한다.

> 현재 모델에서 direct target과 native layer delta를 한 번만 계산한다. Native-equivalent allocation을 시작점으로 두고, historical/pretrained dual barrier 아래에서 모든 layer coefficient를 8–10 step joint하게 탐색한다. Trajectory 중 가장 좋은 feasible allocation을 선택한 뒤 weighted delta를 모든 candidate layer에 한 번만 atomic commit한다.

가장 먼저 확인할 질문은 세 가지다.

1. **고정 native delta의 재배분만으로 실제 preservation gain이 발생하는가?**
2. **같은 계산량의 일반 coefficient optimizer보다 barrier-aware ODE가 더 안전한가?**
3. **현재 parameter-space multi-step ODE-edit의 이점을 one-shot allocation으로 대체할 수 있는가?**

이 세 질문에 대한 결과만으로도 후속 방향을 명확히 나눌 수 있다. Allocation gain이 확인되면 ODE-Alloc을 확장하고, ODE advantage가 없으면 adaptive allocation만 유지하며, V1의 상한이 낮으면 direct per-layer delta basis V2로 이동한다.
