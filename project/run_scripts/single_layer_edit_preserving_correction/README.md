## Reuse boundary

`preparation.py` produces the item-level reuse matrix before GPU admission.
`reuse_bindings.py` binds retained cold7 B1 native and canonical observations.
B1 native fit and actual WN are reused; missing correction and observers are
new. B2–B10 old sequential outputs are not independent cold episodes. Covered
W0 pair observations and B1 N4 pairs are reused without inventing original
token-level payloads. Greedy32 and missing observer panels are new only.

Each M array element owns a different 100-request interval and resets fresh
W0/M0. Its eight arms share one native capsule. M cells specify history0;
this is not a sequential continuation. All80 final L4 tensors are mandatory
local outputs. Original raw files and older no-checkpoint policies are not
modified. Raw/tensor/prompt payloads must never enter Git.

## Source responsibilities

- `alltoken.py`: exact full-weight all-token cached suffix and independent
  physical selected-weight leaf route. No writer-key support restriction.
- `geometry.py`: FP64 exact allowed-range/intersection, streamed TSQR+SVD,
  original-shape rank threshold and ambiguity policy. No Gram rank shortcut.
- `optimizer.py`: fixed Polyak/backtrack/actual-FP32 Armijo and guard rules;
  no scheduler, native fit or evaluator. Every trial is persisted before a
  decision. Technical errors cannot become normal native fallback.
- `runtime.py`: original read-only native fitter, token/teacher/cold capsule,
  immutable native anchor, per-sequence guards and actual nullspace response.
- `technical.py`: actual cold8 validation. CPU fixtures do not imply T_READY.
- `technical_resume.py`: only the explicitly bound receipt-serialization
  failure boundary; saved valid native/gradient/Pstar stages are reused.
- `runner.py`: all arm selections sealed before official P/N/greedy/Dev128;
  endpoint save+CPU reload; no post-observer controller feedback.
- `observer.py`: canonical evaluator adapter and exact retained-row reuse.
  W0 full1k subsets retain their historical padding/population provenance.
- `control.py`, `admission.py`: create-once execution closure and held
  resource/owner/source/argument inspection, then release. No model process
  submits jobs and no repeated submission is implicit.

## Technical limits and execution boundary

T uses two cold8 native fits, fixed teacher/noop repeats, direct-vs-cached
gradient, exact geometry, fixed12-scale signed FD for EN-F/CA/random, and
actual protected full-vocabulary response. All original ceilings remain
fixed. Native-repeat or teacher PASS alone is not T_READY, and T_READY alone
is not M_INITIAL_VALID. Empty/unresolved spaces retain their typed meaning.

The M initial marker covers the actually observed EN-F episode path,
retained endpoint, post-selection observer nonmutation and independent cold
reset; it does not claim all M completed or efficacy. After that marker—or
verified GPU-resource shortage with all needed M normally released and no
running M—the agent stops monitoring. Submitted M programs continue normally.

```text

```

This imports no pretrained model and makes no GPU allocation. Technical and
M commands are provided only by sealed launcher/lock receipts, not by a
generic automatic experiment loop. A new source freeze requires clean tracked
closure; numerical T applicability is checked separately from new M routing.

Cost is recorded by actual phase/call and allocation. Prior native fitting,
teacher preparation, T failures and current M work have separate lineages.
Large geometry/gradient/storage bounds are planning estimates, not measured
GPU utilization or a scientific performance threshold.
