# BLUE L4-only progress-preserving barrier

Authority: `plans/global/2026-09-11-blue-l4-only-progress-preserving-barrier-experiment-design.md`, SHA256 `30be08eccc4b74b34acfeb9e3deb5cbffc9e6c4a02768e6f69fddf5593d99a8e`.

This package is an isolated adapter over the existing ABC objective, panel and evaluator primitives. It does not invoke the old ABC optimizer or Euclidean soft filter. The execution source is recorded in each runtime receipt; the later analysis source is separately sealed. Scientific results are not inferred from source or unit-test validity.

## Fixed experiment

- Exact saved WN, `W = WN + X @ Ub.T`, `X0 = 0`, single L4 down-projection.
- FULL FP32 model/write, FP64 reduced geometry; actual saved Ub Gram.
- Fixed We teacher and pre-native history. Native/compute-z/history calls are zero.
- Early/Middle/Late H/R/EP N8, then Middle Free/J4/N16: 12 trajectories, 104 logical steps.
- No performance selection, threshold tuning, extra seed, sequential extension or early stop.
- Intermediate Curve1100 and terminal Full3900 are kept distinct. Plotting uses the exact common Curve inventory extracted from the terminal Full.
- The stored NLL margin is always `true_nll - new_nll`; NS succeeds for negative margin, RS/PS for positive margin. Ties fail.

## Terminal analysis, not a new experiment

Use four immutable terminal roots: Middle-main, Early-main, Late-main and Middle-auxiliary under the recorded local attempt. Analysis refuses incomplete trajectories or mismatched identities. All output paths are create-once.

```bash
python -m project.run_scripts.blue_l4_progress_barrier.analysis --runs <four terminal roots> --output <new report root>
python -m project.run_scripts.blue_l4_progress_barrier.publication prepare --runs <four terminal roots> --report <report root>
python -m project.run_scripts.blue_l4_progress_barrier.report --report <report root>
python -m project.run_scripts.blue_l4_progress_barrier.publication verify --report <report root>
python -m project.run_scripts.blue_l4_progress_barrier.publication reproduce --report <report root>
```

`geometry_analysis` reconstructs fixed H_N spectra and initial free-energy diagnostics from saved CPU tensors. It never loads an inference model. Later-node free-energy fractions were not saved and must remain NOT_RECORDED. Matched-probe risk is reduced-coordinate risk; it must not be relabelled as full-weight actual FP32 risk.

PNG files are generated by the repository Python plotting code, not an image-generation tool. Numeric request rows, reconstructable X snapshots, Ub/WN references and all original raw files remain at the local preservation root. Publication includes only source, raw-free summaries and hash references. No original raw asset is overwritten.
